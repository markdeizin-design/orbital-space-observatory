# Earth texture sources

- `day.jpg`: NASA Blue Marble Next Generation, January 2004, natural-color base map without added topographic or bathymetric shading. Original 21600 × 10800 reduced to 8192 × 4096, JPEG quality 87 (3.46 MB). [Source image](https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-base/january/world.200401.3x21600x10800.jpg). [Dataset](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/). Credit: Reto Stöckli, NASA Earth Observatory (NASA Goddard Space Flight Center). NASA notes that deep ocean regions in this composite use a uniform blue base; the shader balances that near-black blue for the exhibition's daylight exposure while preserving continental detail. This is not a live photograph or current weather.
- `night.jpg`: NASA Earth Observatory, Black Marble 2016, 3600 × 1800. Re-encoded as JPEG quality 90. [Source image](https://assets.science.nasa.gov/content/dam/science/esd/eo/images/imagerecords/144000/144898/BlackMarble_2016_01deg.jpg). [Source record](https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/). Credit: NASA Earth Observatory images by Joshua Stevens, using Suomi NPP VIIRS data from Miguel Román, NASA Goddard Space Flight Center.
- `clouds.jpg`: NASA Blue Marble cloud composite. Original 8192 × 4096 TIFF converted to grayscale, reduced to 4096 × 2048 and JPEG quality 91. [Source image](https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57747/cloud_combined_8192.tif). Credit: NASA Goddard Space Flight Center; Reto Stöckli, enhancements Robert Simmon. This archival composite is a real satellite-derived cloud distribution, not current weather; it is rendered on a separate rotating transparent sphere.
- `day-4k.jpg` (4096 × 2048) and `clouds-2k.jpg` (2048 × 1024): compact derivatives of the above day/cloud textures, resized with Lanczos filtering and JPEG quality 90. The same NASA sources and credits apply. Selected once on scene mount for viewports narrower than 700 pixels or devices whose maximum texture size is below 8192; resizing does not trigger another texture download.
- `water-mask.png` (4096 × 2048): dedicated NASA Blue Marble land/sea mask, converted to white water/black land with 0.45-pixel edge softening to avoid aliasing. [Source PNG](https://svs.gsfc.nasa.gov/vis/a000000/a003400/a003487/landmask4K.png). [NASA SVS source record](https://svs.gsfc.nasa.gov/3487/), which identifies it as the land/sea mask matching the Blue Marble map. Credit: NASA/Goddard Space Flight Center Scientific Visualization Studio; Blue Marble Next Generation data courtesy of Reto Stöckli (NASA/GSFC) and NASA Earth Observatory. Used as a linear data texture, not a color image.

NASA describes these Blue Marble images as freely available to educators, scientists, museums and the public: [Blue Marble source and credit](https://science.nasa.gov/earth/earth-observatory/the-blue-marble-true-color-global-imagery-at-1km-resolution/). [NASA image/media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/). This independent educational project is not endorsed by NASA. No NASA insignia used for branding.

The scene's lighting, relative sizes, rotation speed and positioning are exhibition choices rather than a calibrated physical simulation. Deep ocean blue is balanced for daylight exposure using the dedicated NASA land/sea mask; continental saturation is reduced 10% and a subtle view-dependent blue haze represents aerial perspective near the limb.
